En aquesta entrada us explico com instal·lar i fer servir un petit script de python que he escrit. Aquest script es connecta a l’API d’OpenAI per usar GPT-3.5_turbo per traduir fitxers d’un idioma a un altre. Tant és que siguin fitxers llargs. Cal tenir una clau API d’OpenAI per fer servir el programa. Aquesta API té un cost, però és molt baix, de l’ordre d’1 cèntim d’euro la traducció.

La major part d’aquesta entrada està escrita amb ChatGTP i serveix d’exemple de com de senzill és escriure documentació i apunts amb aquesta eina. En qualsevol cas, jo en sóc l’editor, sóc jo qui decideixo què vull que s’expliqui i, per tant: jo en sóc l’autor. Podem debatre aquest tema, que no és trivial.

Instal·lar GitHub Desktop
#

Què és GitHub?
#

Segons ChatGPT

GitHub és com un Google Drive per a programadors, però amb algunes característiques addicionals molt útils. Imagina que estàs treballant en un projecte i vols desar-ne versions diferents per poder tornar a una versió anterior si alguna cosa surt malament. Això és el que fa GitHub. A més, si treballes en equip, cada membre pot treballar en parts diferents del projecte al mateix temps, i després GitHub ajuda a unir tota la feina de manera ordenada. Finalment, també és com una xarxa social per a programadors, perquè pots compartir els teus projectes amb altres, i fins i tot col·laborar en projectes d’altres persones.

És una bona explicació.

Instal·lar GitHub Desktop
#

GitHub Desktop és una interfície gràfica que permet interactuar amb GitHub sense usar la línia d’ordres. És útil per gestionar repositoris, fer commits, push i pull, resoldre conflictes, entre d’altres coses. Aquí tens unes instruccions breus per instal·lar-lo a Windows:

  1. Ves a la pàgina oficial de GitHub Desktop a https://desktop.github.com/

  1. Fes clic al botó “Download for Windows (64bit)” si el teu sistema operatiu és de 64 bits. Si no n’estàs segur, ho pots comprovar anant a Configuració de Windows -> Sistema -> Quant a -> Tipus de sistema.

  2. Un cop descarregat el fitxer .exe, fes doble clic a sobre per començar la instal·lació.

  3. Segueix les instruccions que apareixen a la pantalla per completar la instal·lació.

  4. Un cop completada la instal·lació, podràs obrir GitHub Desktop des del menú Inici de Windows.

  5. La primera vegada que obris l’aplicació, et demanarà que iniciïs sessió amb el teu compte de GitHub. Si no en tens, el pots crear a https://github.com/

  6. Un cop hagis iniciat sessió, pots començar a usar GitHub Desktop per gestionar els teus repositoris de GitHub.

Instal·lar Python
#

ChatGPT diu que:

Python és un llenguatge de programació, és a dir, una manera de donar instruccions a un ordinador. És com una recepta de cuina per a la màquina: li dius exactament què ha de fer i com fer-ho. Allò que fa especial Python és que està dissenyat per ser fàcil de llegir i escriure. És com un llibre de receptes que s’esforça per ser senzill i clar, evitant les complicacions innecessàries. Per això, sovint s’utilitza per ensenyar programació als principiants. Però no t’equivoquis, Python és molt potent i s’utilitza en molts àmbits, des de llocs web fins a recerca científica i desenvolupament de jocs.

A més, hem de tenir en compte que és un llenguatge interpretat:

Un llenguatge interpretat, com Python, és un tipus de llenguatge de programació que s’executa línia per línia, és a dir, en temps real. Imagina que ets en una obra de teatre i el director et va dient què fer escena per escena, en comptes de donar-te tot el guió d’un cop. Així funciona Python: l’ordinador va llegint i executant les instruccions del codi que has escrit una per una.

Això té alguns avantatges, com que és més fàcil d’aprendre i d’usar, a més de permetre’t provar parts del codi a mesura que avances. Tanmateix, pot ser una mica més lent que altres llenguatges que es compilen (és a dir, es tradueixen completament a llenguatge de màquina) abans d’executar-se.

Per instal·lar Python 3.10 a Windows, pots seguir aquests passos:

  1. Ves al lloc web oficial de Python a https://www.python.org/

  2. Fes clic a la pestanya “Downloads” a la part superior de la pàgina.

  3. Veureu un botó que diu “Download Python 3.10.x” (x serà un número depenent de l’última versió disponible). Fes clic en aquest botó per descarregar l’instal·lador.

  4. Un cop el fitxer .exe s’hagi descarregat, fes-hi clic per obrir l’instal·lador.

  5. A la finestra de l’instal·lador, assegura’t de marcar la casella “Add Python 3.10 to PATH” a la part inferior. Això farà que puguis usar Python des de la línia d’ordres de Windows.

  6. Després, fes clic a “Install Now”.

  7. L’instal·lador començarà a copiar fitxers i configurar Python al teu sistema. Aquest procés pot trigar uns minuts.

  8. Un cop la instal·lació s’hagi completat, veuràs una pantalla que diu “Setup was successful”. Ja tens Python 3.10 instal·lat al teu sistema!

  9. Per comprovar que la instal·lació ha estat correcta, pots obrir la línia d’ordres (CMD o PowerShell) i introduir l’ordre python --version. T’hauria de mostrar la versió de Python que acabes d’instal·lar.

El que no diu ChatGPT és que t’has d’assegurar de marcar “afegir python.exe” al PATH.

…i eliminar la limitació de longitud del PATH (Disable path length limit).

Instal·lació de l’API d’OpenAI per a Python
#

Per instal·lar l’API d’OpenAI per a Python, necessitaràs fer servir pip, que és una eina que ve amb Python i serveix per instal·lar paquets o biblioteques addicionals.

Segueix aquests passos:

  1. Obre la línia d’ordres de l’ordinador. A Windows, pots cercar “CMD” o “Command Prompt” al menú d’inici.

  2. Un cop oberta la línia d’ordres, escriu la següent ordre i prem Enter:

pip install openai

Potser “pip” no funciona al teu sistema i has d’usar “pip3”

  1. Espera que es completi la instal·lació. Veureu diversos missatges a la línia d’ordres mentre es descarrega i s’instal·la el paquet.

Obtenir una clau d’accés a l’API d’OpenAI
#

Per obtenir una API Key d’OpenAI, has de seguir aquests passos:

  1. Ves a la pàgina web d’OpenAI a https://beta.openai.com/signup/ i crea un compte si encara no en tens.

  2. Un cop hagis iniciat sessió, ves al Dashboard (tauler de control).

  3. Al Dashboard, cerca la secció de “API Keys” (Claus API).

  4. Fes clic a “Create new API Key” (Crear clau API nova).

  5. Et demanarà que escriguis un nom per a la clau i que seleccionis algunes opcions. Un cop ho hagis fet, fes clic a “Create”.

  6. Et mostrarà una API Key nova. Assegura’t de copiar-la i desar-la en un lloc segur, ja que no la podràs tornar a veure.

  7. Ara pots fer servir aquesta clau API al teu codi per interactuar amb l’API d’OpenAI.

Recorda tractar la teva API Key com si fos una contrasenya, ja que proporciona accés al teu compte d’OpenAI i als serveis de pagament. No la comparteixis amb ningú i no la publiquis en llocs públics com repositoris de codi a GitHub.

És possible que hagis de donar d’alta un mecanisme de pagament a la plataforma, ja que l’accés a les API és de pagament. Per fer proves amb models com GPT-3.5_turbo el cost és molt baix. De l’ordre de cèntims o mil·lèsimes d’euro per crida. Models com DALL-E o GPT-4 són més cars.

GDPR i API d’OpenAI
#

OpenAI, amb seu als Estats Units, no ha de rebre dades personals d’usuaris europeus a través de la seva API sense garanties de compliment de la GDPR. Això vol dir que, quan utilitzis l’API d’OpenAI, t’has d’assegurar de no enviar dades que puguin identificar una persona, com noms, adreces de correu electrònic, números de telèfon i qualsevol altra dada que es pugui usar per identificar algú.

És important entendre que la responsabilitat de garantir que les dades enviades a l’API d’OpenAI compleixin amb la GDPR recau en l’usuari que envia les dades. Per tant, sempre has d’anar amb compte a l’hora de gestionar i processar dades personals i assegurar-te que estàs complint totes les lleis i regulacions aplicables.

( Si vols fer servir l’API d’OpenAI amb dades sensibles a Europa has d’usar la versió de l’API al Cloud de Microsoft Azure https://azure.microsoft.com/en-us/products/cognitive-services/openai-service/ )

El meu programa de traducció
#

El meu programa de traducció es troba al meu repositori de GitHub https://github.com/granludo/gpt-test , a la carpeta file-translator. Has d’usar GitHub Desktop per clonar la carpeta al teu ordinador.

Aquestes són les instruccions del Readme.md en castellà:

Per Marc Alier @granludo https://wasabi.essi.upc.edu/ludo

Llicenciat sota la Llicència Pública General de GNU v3.0

Programa simple en Python 3 que utilitza el model GPT-3.5-turbo d’OpenAI per traduir fitxers d’un idioma a un altre. Divideix el fitxer en fragments de 20 línies.

requisits
#

Necessites tenir una clau per usar l’API d’OpenAI, la pots obtenir aquí: https://beta.openai.com/docs/developer-quickstart/api-key aquest programa busca la clau en un fitxer indicat a la variable “mykeypath” per defecte a la ruta ‘..//..//mykey.json’. (És a dir, dins de la carpeta de GitHub)

Exemple del contingut de mykey.json:

{ “key”: “sk-7QzXHpaajenpuakn1tgHT3Bxxxxxxxxxxx” }

Necessites instal·lar els paquets json i openai

pip install openai

python3 gpt-traductor.py archivo_origen idioma_origen idioma_destino archivo_destinoExemple
